## Problem Statement

Students spend too much time rewriting notes and jumping between apps to revise effectively. The workflow is fragmented, slow, and hard to measure.

## Why I built it

I wanted a project that combines AI, content generation, and practical learning workflows in one polished product.

## Features

- Instant quiz generation from raw notes
- Smart summaries in multiple reading depths
- Focus mode with timed revision sessions
- Save and revisit weak topics
- Clean analytics for study streaks

## Technologies Used

C++, Python, NumPy, Matplotlib, and Pandas with an AI API layer for structured responses.

## Challenges faced

The hardest part was keeping the interface minimal while handling AI outputs that can vary in length and structure.

## Solutions implemented

I used a strict response format, progressive loading states, and a modular content layout so the UI stays predictable.

## Lessons Learned

Small UX details matter more than raw feature count when you want a tool to feel premium.

## Future Improvements

- Personalized study plans
- Offline revision mode
- More granular analytics
